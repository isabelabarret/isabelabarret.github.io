# Portfólio Interdisciplinar | Isabela Barreto

Este repositório contém o código-fonte do portfólio profissional de **Isabela Barreto**, hospedado via GitHub Pages em [isabelabarreto.github.io](https://isabelabarreto.github.io).

## 🎯 Proposta & Posicionamento
O portfólio destaca a intersecção única entre:
- **Sustentabilidade Corporativa & ESG**: Gestão nacional de logística reversa de grande porte (R$ 3M), economia circular e inventários de emissões GEE (GHG Protocol Escopos 1, 2 e 3).
- **Inteligência de Dados & Estatística Avançada**: Modelagem em R (GLMM), automação com Python, SQL, Power BI e nuvem AWS.
- **Engenharia Territorial & Geoprocessamento**: Análise espacial com QGIS, diagnósticos ambientais urbanos e tecnologias descentralizadas de saneamento.
- **O Modelo Pedagógico da UFABC**: Formação interdisciplinar inicial pelo BC&T integrada às graduações em Engenharia Ambiental e Urbana e Ciências Biológicas.

## 🛠️ Tecnologias Utilizadas
- **HTML5 Semântico** com acessibilidade e metadados otimizados
- **CSS3 Moderno** com Glassmorphism, Design Tokens, variáveis nativas e responsividade completa
- **JavaScript Puro (ES6+)** para interatividade, filtragem dinâmica de cases e animações sob demanda
